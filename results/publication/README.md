# Publication bundle: generated before the pipeline corrections

Everything in this directory is generated by `scripts/run_publication_package.py`
and `scripts/export_supplementary_tables.py`. The committed copy was produced
**before** the corrections in PR #41 and is kept as a record of that run; it has
not been regenerated in place, because hand-editing generated output would make
it misstate what produced it.

Known to be superseded:

- **`supplementary/S6_yeast_pilot_hits.csv`** lists P07264 (LEU1) as a hit. That
  score rested on a mislabelled depth input and is withdrawn; see
  `results/yeast_pilot/README.md`.
- **`RESULTS_SUMMARY.md` and the benchmark counts** use burial classes from
  ligand SASA summed over every copy in an entry. Measured per copy, the benchmark
  is 89 surface, 26 semi-cryptic, 14 cryptic and 6 crystal artefacts.
- **Tier-1 separation** under the current scorer is 0.581.

The corrected numbers and their evidence are in `docs/METHODS.md` and
`manuscript/RESULTS_DRAFT.md`. To regenerate this bundle from the current code:

```bash
python scripts/run_publication_package.py --output-dir results/publication --skip-dataset-build
```

Regeneration needs RCSB access and fpocket, so it runs in CI rather than in an
offline environment.
